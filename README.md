# 个人作品集网站

这是一个使用 React、TypeScript 和 Tailwind CSS 构建的个人作品集网站。

## 技术栈

- React 18+
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion (动画)
- React Router DOM (路由)

## 功能

- 响应式设计
- 深色主题
- Hero 部分（首页）
- 项目展示部分
- 渐变色和动画效果

## 部署

此项目已配置为可在 Vercel 上一键部署。

## 开发

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```
